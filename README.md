# Employee Salary Analytics Dashboard | Power BI

## Project Overview
This project presents an interactive Power BI dashboard designed to analyze employee salary data across five departments. It provides clear salary insights, employee distribution, and department-wise comparisons through interactive visualizations.

## Key Features
- **Average Salary KPI** — Displays the average employee salary.
- **Median Salary KPI** — Shows the median salary.
- **Total Employees KPI** — Displays the total employee count.
- **Department-wise Salary Analysis** — Compares average salaries across departments.
- **Employee Distribution** — Visualizes employee counts by department.
- **Interactive Filters** — Explore data using Name and Department slicers.
- **Key Findings** — Highlights important insights from the analysis.
